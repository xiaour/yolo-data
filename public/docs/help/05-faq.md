# 常见问题与排错

## 数字对不上：先查这 4 处

按顺序核对回答中的「查询范围」：

1. **时间区间**：是不是"本月=1日至昨天（T-1）"这类右边界差异？
2. **含税 / 未税**：未指定时平台默认按**含税**；你报表若是未税口径，直接说"按未税"重问。
3. **数据集 / 指标来源**：回答走的是指标平台还是业务数据集？两边算法可能不同。
4. **过滤条件**：行级权限会强制附加过滤（如只看华东区），你看到的数是"你被授权的范围"。

以上都一致仍对不上 → 把「问题 + 查询范围截图」发给管理员，用「运行审计」里的执行记录对账。

## 提示「指标平台未配置」

底部运行框显示红色「指标平台未配置」时：

- 当前环境未配置指标平台连接（`.env` 中的指标平台地址）。
- 平台自动切换为**大模型直连模式**：直接使用业务数据集和工作区产物回答。
- 管理员可在「系统设置」中启用并配置指标平台，或明确保持直连模式。

## 提示模型相关错误

- **模型未配置**：管理员到「模型管理」新增 DeepSeek 或兼容模型并设为默认。
- **密钥无效 / 连接失败**：检查 Base URL 与密钥；主题绑定的独立密钥会覆盖平台默认。
- 当前环境未配置任何模型时，平台可能以**本地规则模式**运行，仅支持有限演示，正式使用必须配置模型。

## 追问后答案变了？

- 同一会话内追问**复用上一轮数据快照**，结果应一致；若不一致，先看「查询范围」时间是否被上下文改写。
- 换新话题请点「开始问数」开新会话，旧上下文（时间、过滤）会被继承，这是特性不是 bug。

## 回答说「当前在线能力无法完整回答」

不是故障。说明所需指标/维度未上线，回答里已给出缺口与建设建议，转给管理员即可。

## 看不到某主题 / 某指标

主题、指标、数据集均按用户授权显示。联系管理员在「数据权限」中添加。

## 忘记密码

联系管理员；管理员可在用户管理中重置。自己记得旧密码时用右上角账号菜单「修改密码」。

## 登录后会话经常失效

会话由 Cookie 维持，服务重启后可能需要重新登录。生产部署建议接入 SSO/OIDC（平台已列入规划）。
