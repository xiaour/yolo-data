# 核心概念速查

> 面向所有用户。看懂这 6 个词，看回答就不会迷路。

## 智能体（Theme Agent)

一个主题就是一个独立的业务 DataAgent：独立的提示词、模型、Skills、指标范围、数据集范围和默认口径。「销售经营」主题里的"销售额"和「采购」主题里的"采购额"互不干扰。**问数前先选主题，是得到正确答案的第一步。**

## 指标口径

每个指标有确定义：时间规则、过滤条件、聚合方式、展示格式。平台直接对接指标目录读取口径（不复制、不拿缓存当事实来源）。你看到的"含税销售额"在平台里只有一种算法，这就是答案稳定的原因。

## 查询契约（Contract-first）

你的自然语言问题会被编译成一份**查询契约**：时间范围、字段绑定、筛选条件、排序全部冻结后才执行。回答中的「查询范围」段落就是这份契约的回显。**先核对查询范围，再采信数值。**

## 时间右边界（T-1）

未完结周期（本月 / 本周 / 今年 / 近N天）一律统计到**昨天**。数据通常在当天才完整，取到 T-1 是为了避免"半天的数"造成的误读。要含今天请明确说。

## 工作区产物

每次查询的表格、代码执行结果和文件（CSV / JSON / XLSX）都保留在会话的工作区，可随时从右上角「工作区产物」下载。**追问优先复用已有数据快照**，所以同一会话里追问"再按渠道拆一下"不会重新取数、也不会出现两个不同的总数。

## 会话记忆

会话按「用户 × 主题」隔离：你在销售主题里的上下文不会漏进采购主题；别人也看不到你的会话。点左侧「开始问数」开新会话即可清空上下文重新开始。

## 长期记忆

会话记忆只服务当前这一轮上下文。想让平台记住可以长期复用的业务知识与习惯，用**长期记忆**。它由三部分组成：

- **记忆文档**：按「用户 × 智能体」各一份 Markdown 手册，用 `## 分节` 组织。摘要会常驻问数上下文，正文按需检索，所以不必把细节塞进摘要。
- **笔记**：追加式的原始记录，只增不改语义。回答结束后平台会自动从这段对话提炼笔记，也可以在「我的记忆」里点「从会话沉淀」按需提炼，或「新增笔记」手工写。
- **版本**：每次合并、压缩或人工编辑都会生成一个快照，可随时回滚到历史版本。
- **自动整理**：平台会自己维护这份手册——每轮问答后攒够一批笔记就自动合并，后台每 15 分钟再巡检一次，把零散笔记收进文档、把过长的正文压缩去重。压缩只在有可用大模型时进行，宁可少压缩也不丢信息。

怎么用：

- 记录什么：你自己确认过的业务口径、术语与字段的对应关系、常用时间范围和分析偏好，不记录某次查询的数值。
- 怎么生效：问数时自动注入文档摘要，用来补全你没明说的默认口径，减少重复澄清。与智能体提示词、平台规则或你本轮的说法冲突时，一律以后者为准。
- 怎么管理：在头像菜单的「我的记忆」里只能看到你自己的记忆，点「合并笔记」「压缩」可手动整理；可编辑摘要与正文、暂停注入、查看版本并回滚、清空整个作用域。管理员在「系统设置 → 记忆管理」才能查看全部用户的记忆。没配置大模型时，只沉淀你在提问里明确说「记住……」的内容，并退化为按类型追加。

## 一图流：一个问题是怎么被回答的

```
你的问题
  → 语义层：匹配指标/数据集字段口径
  → Skill 审计：规划前核对口径
  → 契约编译：时间、维度、筛选冻结成查询契约
  → 权限校验：主题/指标/数据集 + 行级/列级策略
  → 执行：只读查询、结果稳定化
  → 工作区：留存表格与文件
  → 回答：结论 + 查询范围 + 结果分析 + 图表
```

任何一步不通过（口径不明、时间不明、权限不足），平台会**反问或拒绝**，而不是猜一个数字给你。
