# 结合本地文件算数

> 适用对象：分析员。目标：把你手头的 Excel / CSV 交给平台，和指标查询结果一起做对账、拆解与补充计算。

## 1. 这个能力解决什么

平台原本只能查指标平台里的数。现实中你常常需要拿**自己的一份表**去和平台数据核对，例如：

- 用供应商对账单核对本月采购入库金额；
- 把预算表贴上来，算各区域目标完成率；
- 指标里没有的字段（业务员、门店备注），用本地文件补上再分组。

上传后，Agent 会把文件当成**当前会话的一等数据源**，可以和指标结果、业务数据集结果一起精确计算。

## 2. 怎么上传

1. 进入「开始问数」，在**输入框上方**点「本地文件」按钮，选择文件；也可以直接把文件拖到那一行。
2. 上传成功后会出现一个文件标签，说明识别到的行数与列数。
3. 在输入框写下你的问题，**发送时这份文件会随提问一起提交**。
4. 发送后，你的提问气泡里会显示本轮引用的文件，方便回溯。

支持格式：**CSV、XLS、XLSX**。中文 CSV 的 GB18030 编码会自动识别。

## 3. 怎么提问

文件挂上以后，正常提问即可，尽量**点名文件**：

| 好问法 | 说明 |
| --- | --- |
| 用「回款明细.xlsx」核对本月回款额，差异按客户列出 | 点名文件 + 明确指标 + 时间 |
| 把「预算表.csv」和上面这个月的销售额合并，算各区域完成率 | 文件 + 引用上一轮结果 |
| 「订单明细.xlsx」里按业务类型汇总含税金额，和指标结果对比 | 文件内部分组计算 |

- 你说的「这份文件 / 这个表 / 用它算一下」，默认指**本轮提问携带的文件**。
- 文件在会话内一直可用，**追问时不用重复上传**；但气泡里只会显示当轮引用的文件。

## 4. 上传后平台做了什么

每份文件在「工作区产物」里对应三份产物：

| 产物 | 内容 |
| --- | --- |
| 原始文件 | 你上传的字节原样保留，供精确计算与下载 |
| 解析表 | 识别出的表头、列类型（文本 / 数值 / 日期）与数据行 |
| 过程文件 | 解析这一步的编码、分隔符、行数、列数与字段角色建议 |

计算统一走平台的代码执行环节，因此对账、跨文件合并、复杂透视、图表与 Excel 导出都能做，且**全过程留痕可核查**。

## 5. 限制与注意

- 单文件 ≤ **8MB**；单会话最多 **20** 个文件、合计 ≤ **40MB**。
- 解析表默认只保留前 **50,000 行**。文件更大时上传提示会写明真实总行数，**完整数据用原始文件参与计算**，不要用截断后的样本下结论。
- XLSX **只解析第一个工作表**；需要其它工作表时请另存为一个单独文件。
- 旧版二进制 `.xls`（Excel 97-2003 格式）只保存原文件、不解析内容，会提示你「另存为 .xlsx 或 .csv」。
- 文件数值没有指标平台口径，回答中会**标注来源**，不会被表述成指标平台数据。文件口径与平台口径冲突时，以你当轮的说明为准并回显差异。

## 6. 数据安全

上传文件属于**你的自有数据**：

- 只在**当前会话**内可见，不跨用户共享，也不会写入知识库或反馈沉淀；
- 上传与拒绝都会记录审计，包含文件名、大小与指纹；
- 无法解析的格式或伪装成表格的二进制文件会在入库前被拦下。

## 7. 常见问题速查

| 现象 | 原因与处理 |
| --- | --- |
| 提示「暂不支持 .txt 文件」 | 只接受 CSV / XLS / XLSX，请先转换格式 |
| 提示「文件不是有效的 xlsx 工作簿」 | 文件可能被改过后缀或已损坏，请用 Excel 重新导出 |
| 提示「请另存为 .xlsx 或 .csv」 | 上传的是旧版二进制 `.xls`，按提示转换即可 |
| 文件里有数据但解析表行数变少 | 触发了 50,000 行上限，平台会写明真实总行数 |
| 中文列名显示乱码 | 少见；请把文件另存为 UTF-8 编码的 CSV 后重试 |
