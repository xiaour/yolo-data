# 问数技巧与提问模板

> 目标：把问题问清楚，让答案一次到位。平台按「对象 + 指标 + 时间」理解问题，三个要素越全，反问越少。

## 万能公式

```
[时间] + [对象/维度] + [指标] + [筛选/排序/数量]
```

示例：**近30天**（时间）+ **各销售大区**（维度）+ **含税销售额**（指标）+ **TOP5、从高到低**（排序与数量）。

## 按场景选择问法

### 趋势
- 近7天各区域销售额趋势如何？
- 今年1月至今每月毛利率变化怎么样？

### 对比（环比 / 同比）
- 8月各渠道销售额环比变化如何？
- 本季度华东区销售额同比去年增长多少？

### 排名
- 本月含税销售额TOP5的销售大区，按金额从高到低。

### 占比 / 结构
- 本月各业务类型的销售额占比是多少？

⚠️ 占比、贡献、份额类问题必须说清**分子和分母**（例：占哪个范围的百分比）。说不清时平台会先反问，这是刻意设计，防止口径拍脑袋。

### 多条件筛选
- 上海地区本月毛利率低于30%、销售额大于10万的客户有哪些？

## 时间怎么说才不会被反问

| 你说 | 平台理解为 |
| --- | --- |
| 本月 | 本月1日 至 昨天（T-1） |
| 本周 | 本周一 至 昨天 |
| 近7天 | 不含今天的最近7天 |
| 8月 | 8月1日 至 8月31日（完整月） |
| 含今天 | 明确包含今天的完整区间 |

- 未指定时间且上下文里也没有 → 平台**先反问**，不默认。
- 追问继承上一轮时间：上一轮问了「8月」，追问「按渠道拆开呢」仍是8月。换时间请明说。

## 让答案更稳定的 4 个习惯

1. **一次问一件事**。「各区域销售额和完成率」好于「给我讲讲整体销售情况」。
2. **指标用平台词**。不确定叫什么，先去「指标体系」页搜指标名与口径。
3. **排序和数量说明确**。「按金额从高到低，取前10」。
4. **先核对「查询范围」再采信数值**。时间、数据集、过滤条件不对，直接说「时间改成9月」重新问。

## 能力不足时怎么办

当所需指标或维度未上线，平台不会硬答，会按固定格式回复：

> 当前在线能力无法完整回答「{原问题}」。已核验的「{最接近指标}」缺少「{维度/时间/筛选}」。需要建设「{建议指标}」：…

把这段话转给管理员，就是一份合格的指标建设需求。
