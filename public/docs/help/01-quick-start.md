# 快速上手（分析员）

> 适用对象：分析员角色。目标：10 分钟内完成第一次问数，并看懂回答的每一段。

## 1. 登录与角色

1. 打开平台地址（开发环境默认 `http://localhost:8088/`）。
2. 输入账号密码登录。角色分为**管理员**与**分析员**：
   - 管理员：负责配置平台（模型、数据集、智能体、数据权限）。
   - 分析员：只能查看**已授权**的智能体，并用它问数。
3. 首次登录后，点击右上角账号菜单 →「修改密码」。

## 2. 认识工作台

左侧导航分四区：

| 分区 | 内容 | 你会用到 |
| --- | --- | --- |
| 分析 | 开始问数 | 日常问数主入口 |
| 资产 | 指标体系、智能体（页内含模型管理）、数据集 | 查看可用指标与智能体（只读） |
| 治理 | 数据权限、质量运营、运行审计（页内含数据集查询）、系统设置 | 一般不用管，属于管理员 |
| 帮助 | 帮助中心（页内含使用引导） | 上手清单与文档检索 |

底部运行状态框显示平台连接状态；若显示「指标平台未配置」，表示当前环境未接入指标平台，问数将走业务数据集或本地规则模式，不影响你先体验。

## 3. 选择智能体

进入「开始问数」后，先在**顶部面包屑**切换到你被授权的主题（例如「销售经营」）。

- 一个主题 = 一个独立的业务 DataAgent，限定了指标范围、数据范围和回答口径。
- **换问题先看主题对不对**：销售的问题不要在采购主题里问。
- 看不到某个主题时，联系管理员在「数据权限」中为你授权。

## 4. 提一个好问题

好问题 = **对象 + 指标 + 时间**。

| 问法 | 示例 |
| --- | --- |
| 时间 + 维度 + 指标 | 近7天各区域销售额趋势如何？ |
| 环比 / 同比 | 8月各渠道销售额环比变化如何？ |
| 排名 | 本月含税销售额TOP5的销售大区，按金额从高到低 |
| 筛选 | 上海地区本月毛利率低于30%的客户有哪些？ |

**关于时间的两条规则**（平台按此执行，不是模型随口说的）：

1. 时间没有说清时，平台会**先反问**，不会默认取「本月」或「近30天」。
2. 未完结周期（本月 / 本周 / 今年 / 近N天）一律统计到**昨天（T-1）**；只有你明确说「含今天」才例外。

## 5. 看懂回答结构

回答自上而下：

1. **一句话结论**：对象 + 指标 + 时间 + 数值。
2. **查询范围**：数据集、时间区间、维度、过滤条件。⚠️ 这是平台实际执行的口径，**先核对这一段再采信数值**。
3. **结果分析**：行数、合计、TOP 对象等要点。
4. **图表**：趋势用折线、类别对比用柱状、结构占比用饼图（默认只出一张图）。

## 6. 追问与导出

- **多轮追问**：在输入框继续问，例如「那按渠道拆开呢」。追问优先复用上一轮的数据快照，避免重复取数造成结果漂移。
- **工作区产物**：点右上角「工作区产物」图标，可查看并下载历史查询的表格、代码运行结果和文件（CSV / JSON / XLSX）。
- **换新话题**：点击左侧「开始问数」开一个新会话，避免旧上下文干扰。

## 7. 用本地文件补充计算

你手上有 Excel / CSV 想和平台数据核对时：

1. 在**输入框上方**点「本地文件」（或直接把文件拖进去），支持 **CSV / XLS / XLSX**。
2. 上传后出现文件标签，发送问题时**文件会随提问一起提交**，提问气泡里会显示本轮引用的文件。
3. 提问时点名文件，例如：**用「回款明细.xlsx」核对本月回款额，差异按客户列出**。

文件只在你当前会话内可见，追问时不用重复上传。详见《结合本地文件算数》。
