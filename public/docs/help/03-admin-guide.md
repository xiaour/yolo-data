# 管理员配置指南

> 适用对象：ADMIN 角色。推荐按「模型 → 数据集 → 主题 → 权限 → 审计」的顺序完成首次配置，前一步是后一步的前置。

## 0. 环境准备

```bash
npm run setup        # 安装依赖、从 .env.example 生成 .env（幂等）
npm run dev          # 启动，默认 http://localhost:8088/
```

- 首次部署务必修改默认口令（admin / east_manager / channel_analyst 均为 yolo123456），或用环境变量 `DEFAULT_USER_PASSWORD` 覆盖。
- 所有数据源密码、模型密钥使用 AES-256-GCM 加密保存，密钥不要提交进仓库。

## 1. 模型管理

「模型管理」→ 新增模型：

| 配置项 | 说明 |
| --- | --- |
| Base URL | DeepSeek 或任意 OpenAI 兼容服务地址 |
| 密钥 | 加密保存；主题可用独立密钥覆盖 |
| 温度 / 工具轮次 | 问数场景建议低温；工具轮次决定 Agent 最多可连续调用几次工具 |
| 平台默认模型 | 未单独绑定模型的主题回退到默认模型 |

验证：新建主题时能在模型下拉里选中它，且「运行审计」能看到该模型的调用记录与 Token 消耗。

## 2. 业务数据集

「数据集」→ 新建数据源（当前支持 MySQL 协议，含 Doris）：

1. 填写主机、端口、库名、账号密码，连通性测试通过后保存。
2. **同步结构**：拉取表与字段；「字段」弹窗可逐个启用/禁用（默认全部启用，禁用字段不能作为维度/指标/时间/筛选）。
3. **智能识别**：平台抽样数据自动推断字段角色（`TIME / METRIC / DIMENSION / IDENTIFIER`）、聚合方式与默认时间窗口，**逐项确认后**写回字段口径——这一步直接决定问数时的时间追问频率，务必人工过一遍。
4. 默认枚举值域：给常用筛选字段（如地区、业务类型）配置合法枚举，问数时枚举可"精确直达"，不再靠模型猜。

安全边界：平台用自有只读查询构建器生成查询，**不向模型暴露原始 SQL**；数据集查询全部进入审计。

## 3. 主题智能体

「主题智能体」→ 新建主题（参考示例 `docs/theme-prompts/sales-operation.md`）：

| 配置 | 要点 |
| --- | --- |
| 指标范围 / 数据集范围 | 只勾选本主题该用的；范围越小回答越稳 |
| 运行模型 | 可绑多个模型并指定默认 |
| Skills | 可挂规划前口径审计、执行后结果验证等 SKILL.md |
| 主题提示词 | 放业务口径：展示格式（金额万元/0位小数）、固定过滤、枚举映射、时间规则、输出自查清单 |
| 默认口径 | 如「未指定时默认含税」 |

原则：**业务词、枚举映射、计算公式放主题提示词与字段说明，不要写死在平台代码里**。

## 4. 数据权限

「数据权限」按用户配置：

- **主题级**：用户能看到哪些主题智能体。
- **指标级 / 数据集级**：主题内进一步收窄。
- **行级策略**：强制附加过滤（如只能看华东区），模型同字段条件也覆盖不了它。
- **列级策略**：隐藏或脱敏（如手机号），在浏览器返回前执行。

## 5. 上线前检查清单

- [ ] 默认口令已全部修改
- [ ] 指标平台已配置，或已明确走「大模型直连模式」（系统设置中停用指标平台）
- [ ] 每个数据集跑过一次「智能识别」并确认
- [ ] 每个主题用 3 个典型问题试跑（趋势 / 对比 / 排名）
- [ ] 行级权限用两个不同用户交叉验证过
- [ ] 「运行审计」能看到执行记录与权限变更
